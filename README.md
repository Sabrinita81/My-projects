# Portfolio de Data Science

**Sabrina Benedetto** · Economista · Auditoría del sector público · Ciencia de datos

Proyectos desarrollados durante la carrera de Data Science de **Coderhouse**, ordenados según el recorrido de aprendizaje: del primer modelo de clasificación al procesamiento de lenguaje natural (NLP) y deep learning.

| # | Proyecto | Pregunta | Técnicas principales |
|---|----------|----------|----------------------|
| 01 | [Abandono de clientes de tarjetas de crédito](01-churn-tarjetas-credito/) | ¿Qué clientes van a dar de baja la tarjeta? | EDA, tests estadísticos, PCA, regresión logística, Naive Bayes |
| 02 | [Eficiencia del gasto público en Argentina](02-eficiencia-gasto-publico-argentina/) | ¿Se puede anticipar cómo se ejecutará una partida presupuestaria? | Datos abiertos y API del BCRA, ANOVA, Random Forest, XGBoost, GridSearchCV |
| 03 | [Noticias financieras y el S&P 500](03-nlp-noticias-sp500/) | ¿Los titulares de noticias anticipan si el mercado sube o baja? | NLP (spaCy, TF-IDF, VADER), redes neuronales, FinBERT |
| 04 | [Panel de seguimiento de contratos](04-panel-seguimiento-contratos/) · *caso real* | ¿Qué contratos vencen en 90 días y a qué clientes priorizar? | Python, pandas, control de calidad de datos, dashboard HTML |

## Herramientas

Python · pandas · NumPy · scikit-learn · XGBoost · TensorFlow/Keras · PyTorch · Hugging Face Transformers · spaCy · NLTK · Matplotlib · Seaborn · Plotly

## Cómo ver los proyectos

Cada carpeta tiene un README con el resumen del proyecto y el notebook completo (`.ipynb`), que GitHub muestra directamente en el navegador, con el código, los gráficos y los resultados.
